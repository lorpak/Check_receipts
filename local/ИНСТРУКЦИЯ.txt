Инструкция по использованию CheckReceipts

1. Назначение
CheckReceipts — десктопное приложение для локальной проверки XML-отчетов/отбивок БКИ и формирования Excel-файлов с найденными ошибками.

2. Запуск
1) Запустите приложение CheckReceipts.exe.
2) Откроется окно «Обработка ошибок БКИ».

3. Подготовка данных
Поддерживаются два сценария.

Сценарий A: обработка папок
- Выберите одну или несколько папок с данными.
- Для нескольких путей можно указать их через ; в поле источника.
- Желательная структура:
  - Reports (или report, отчеты)
  - Receipts/Responses (или receipts, responses, отбивки)

Также поддерживается структура CreditLine:
- EquifaxNew/Reports + EquifaxNew/Receipts
- UCBNew/Reports + UCBNew/Receipts
- UCHFNew/Reports + UCHFNew/Receipts

Сценарий B: обработка одного XML-файла
- Нажмите «Выбрать источник» и выберите режим файла.
- Выберите один XML-файл отчета.
- Поддерживаемые префиксы имени файла:
  - 0XY_FCH
  - BD0
  - CHP
  - CHT_
- Рядом должна быть соответствующая отбивка (в той же папке или в подпапке responses/response/receipts).

4. Работа в интерфейсе
1) Выберите источник (папка/папки или один XML).
2) Выберите папку для сохранения результатов.
3) Укажите период обработки: Начало/Конец (или быстрые кнопки Сегодня/Вчера/Последние 3 дня).
4) Выберите тип событий:
   - Все события
   - События 3.2
   - Ежедневные события
5) Нажмите «Обработать файлы».
6) Дождитесь завершения по индикатору прогресса.

5. Результаты
- Файлы сохраняются в выбранную папку.
- После обработки результаты открываются автоматически.
- Имена выходных файлов:
  - errors_3-2.xlsx
  - errors_daily.xlsx
- Если ошибок нет, файл может не создаться.

6. Частые ошибки
- «Укажите папку или XML-файл с исходными данными»
  -> Не выбран источник.
- «Укажите папку для сохранения результатов»
  -> Не выбрана выходная папка.
- «Дата начала не может быть позже даты окончания»
  -> Исправьте диапазон дат.
- «No report/response pairs found...»
  -> Не найдены пары отчет/отбивка, проверьте структуру и имена файлов.
- «Для выбранного файла не найдена отбивка...»
  -> Для одиночного файла не найдена соответствующая отбивка.

7. Полезно знать
- Приложение запоминает последние выбранные пути.
- В dev-режиме запуск: npm run tauri:dev
- Сборка exe/установщика: npm run tauri:build
